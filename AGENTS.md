# Repository guidance

## Project progress tracking

`docs/PROJECT_PROGRESS.md` is the canonical scientific and engineering progress
record for this repository.

After any material experiment, implementation milestone, validated result,
research-question change, or decision-gate change:

1. update `docs/PROJECT_PROGRESS.md` in the same task;
2. update its date, current phase, evidence, conclusion, next work, and change log;
3. keep the README project-status summary consistent with it;
4. preserve negative results and distinguish observations from interpretations;
5. never describe a route as completed until its artifacts or tests exist.

Routine formatting, comments, or unrelated maintenance do not require a
progress update.
